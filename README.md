# BJ.1 Academic Calendar V3.0
เว็บปฏิทินภาษาไทย Responsive สำหรับ GitHub Pages + Google Apps Script + Google Sheets

## ติดตั้งใหม่ / อัปเกรด V2
1. สำรอง Google Sheets เดิมด้วย File > Make a copy ก่อนอัปเกรด ห้ามลบแท็บ Events เดิม ระบบเติมคอลัมน์ต่อท้าย 8 คอลัมน์เดิมและรักษา __backendId เดิมไว้
2. เปิด Extensions > Apps Script ของชีต วาง Code.gs แทนโค้ดเดิม ตั้ง Time zone Asia/Bangkok ทั้งโปรเจกต์และชีต
3. ตั้ง Script properties: SHEET_ID = ID จาก URL ของชีต, ADMIN_USER = BJ1acd, ADMIN_PASSWORD = รหัสผ่านที่กำหนด (ค่าเดิม acd1234 ควรเปลี่ยนเป็นรหัสผ่านสุ่มยาวก่อนเผยแพร่) ห้ามนำรหัสไปใส่ config.js หรือ GitHub
4. Run setup และอนุญาตสิทธิ์ Sheets/Calendar. หากต้องการสำรองทุกวัน Run installDailyBackup เพิ่ม (แท็บ Backup เป็น snapshot ล่าสุด ไม่ใช่ประวัติหลายรุ่น)
5. Deploy > Manage deployments > Edit > New version สำหรับระบบเดิม หรือ New deployment > Web app > Execute as Me > Who has access Anyone สำหรับระบบใหม่ คัดลอก URL /exec
6. ใส่ URL /exec ใน config.js และอัปโหลด index.html, app.js, style.css, config.js, manifest.webmanifest, sw.js, icon-192.png, icon-512.png ไปยัง root ของ repository. เปิด Settings > Pages > Deploy from a branch > main / root. ไม่ต้องอัปโหลด Code.gs ขึ้น GitHub
7. ทดสอบเปิดหน้าเว็บ ตรวจวันหยุด ล็อกอิน เพิ่มกิจกรรมหนึ่งรายการ รีเฟรช แก้ไข ลบ กู้คืน แล้วลบรายการทดสอบตามต้องการ ไม่มีการเพิ่มกิจกรรมสมมติในระบบอัตโนมัติ

## ผู้ดูแลเพิ่มเติม
Script property EXTRA_ADMINS เป็น JSON object ชื่อผู้ใช้:รหัสผ่าน เช่น {"admin2":"รหัสผ่านสุ่มยาว"} เก็บใน Apps Script เท่านั้น ผู้ดูแลทุกคนมีสิทธิ์เท่ากัน ยังไม่ใช่ Google OAuth หรือระบบ RBAC. จำกัดการลองผิดแยกตามชื่อบัญชี (อาจถูกล็อกชั่วคราวได้) และ session เก็บใน cache ฝั่งเซิร์ฟเวอร์ ไม่เก็บรหัสผ่านที่เว็บ ควรจำกัดสิทธิ์ผู้แก้ไข Apps Script และ Google Sheets. หากใช้บัญชีร่วม audit ระบุได้เพียงชื่อบัญชี.

## ฟีเจอร์
- ปฏิทินเดือน สัปดาห์ ปี รายการ, แสดงชื่อกิจกรรมในช่องวัน สูงสุด 3 ชื่อและจำนวนเพิ่มเติม, แถบต่อเนื่องรายสัปดาห์สำหรับกิจกรรมหลายวัน (สูงสุด 4 แถบต่อสัปดาห์), รายละเอียดกิจกรรม, ค้นหา, กรองหมวดหมู่ สถานะ ปีการศึกษา ภาคเรียน, dashboard, DAY/NIGHT, เต็มจอ, auto refresh 5 นาทีเมื่อเปิดหน้าในฐานะผู้ชม, PWA shell
- เวลา ผู้รับผิดชอบ สถานที่ กลุ่มงาน กลุ่มเป้าหมาย ลิงก์ สถานะ ปักหมุด ฉบับร่าง กิจกรรมซ้ำสูงสุด 52 ครั้ง คัดลอก ตรวจช่วงเวลาสถานที่ซ้ำแบบเบื้องต้น, นำเข้า CSV/XLSX ลบหลายรายการ ถังขยะ กู้คืน audit 200 รายการล่าสุด ดาวน์โหลด backup JSON ตั้งชื่อหน้า/โรงเรียน/โลโก้
- รายงานเดือนที่เลือก ปีปฏิทิน ปีการศึกษา/ภาคเรียน สัปดาห์ ทั้งหมด ช่วงวันที่กำหนด, ใช้ตัวกรองได้, A4/A3 แนวตั้ง/แนวนอน, PDF, PNG, XLSX, CSV, ICS
- Google Sheets 999 กิจกรรม (ไม่รวมวันหยุดอัตโนมัติและถังขยะ), ตรวจค่าที่เขียน, version ป้องกันเขียนทับการแก้ไขพร้อมกัน, lock, ตรวจสิทธิ์ฝั่ง backend

## การนำเข้า
หัวคอลัมน์ภาษาอังกฤษ title,start,end,owner,place,details,holiday,startTime,endTime,category,department,audience,status,academicYear,term,link,visibility,pinned. ต้องมี title และ start, วันที่ ISO YYYY-MM-DD หรือ dd/mm/yyyy ตามค่า yearOffset; Excel ควรตั้งเซลล์วันที่เป็นข้อความก่อนกรอก. นำเข้าชีตแรกเท่านั้น. การนำเข้า/ทำซ้ำ/ลบหลายรายการเป็นการบันทึกทีละรายการ หากล้มเหลวกลางทางจะแจ้งจำนวนที่สำเร็จ ไม่ใช่ transaction แบบทั้งหมดหรือไม่ทำเลย.

## วันหยุด
ดึง Google Calendar วันหยุดไทยในช่วงปีก่อนถึงสองปีถัดไป แคช 6 ชม. มีรายการสำรองปี 2569 รวมวันที่ 16 ธันวาคม 2569 วันหยุดราชการกรณีพิเศษตามมติ ครม. 10 พฤศจิกายน 2569. ไม่รวมวันหยุดเฉพาะพื้นที่ กทม. และปริมณฑล 28–29 กันยายน 2569 สำหรับโรงเรียนสุพรรณบุรี. วันหยุดเพิ่มเติมผู้ดูแลเพิ่มได้เอง รายการวันหยุดราชการที่ช่วงวันตรงกับรายการอัตโนมัติจะแสดงรายการที่ผู้ดูแลเพิ่มแทน. แหล่งตรวจสอบ https://www.soc.go.th/?p=33672 และ https://www.thaigov.go.th/uploads/document/74/2026/11/pdf/20261110173458_4547.pdf . ข้อมูลปฏิทิน Google ไม่ใช่ฐานข้อมูลมติ ครม. แบบรับประกันครบทุกปี

## ข้อจำกัด / ตรวจสอบก่อนเปิดใช้งาน
- ผ่านการตรวจ syntax และทดสอบหน้าจอ Chromium ด้วย API จำลอง รวมปฏิทินเดือน/ปี/สัปดาห์ แถบกิจกรรมหลายวัน หน้ารายละเอียด โหมดกลางคืน รีพอร์ต และ Login UI. ยังไม่ได้ทดสอบ API Apps Script จริง การเขียนชีต การพิมพ์ และการสร้างไฟล์จริงบนอุปกรณ์ผู้ใช้
- PDF ยังเป็นภาพตารางเพื่อรักษาภาษาไทย (เลือกข้อความไม่ได้) ไลบรารี PDF/Excel โหลดจาก CDN; หากโหลดไม่ได้ใช้พิมพ์หรือ CSV. ภาพขนาดใหญ่อาจเกินขีดจำกัดของโทรศัพท์
- ปีการศึกษา/ภาคเรียนระบุรายกิจกรรม ยังไม่มีตารางกำหนดวันเปิดปิดภาคเรียนอัตโนมัติหรือนับวันเรียนจริง; หมวดหมู่และสีกำหนดใน cats ใน app.js, ไม่ใช่ CRUD หมวดหมู่ใน Admin
- ยังไม่มี LINE/email push, Google Calendar sync สองทาง, QR generator, ระบบ Google Sign-in, PDF text, หรือกู้คืน JSON ทั้งชุดจากหน้าจอ. สามารถกู้คืนรายการในถังขยะ และผู้ดูแลชีตนำ backup ไปคืนด้วยตนเองได้
- PWA แคชเฉพาะไฟล์หน้าเว็บ ไม่แคชข้อมูลกิจกรรมบนอุปกรณ์ข้ามการเปิดใหม่เมื่อออฟไลน์ เพื่อไม่ให้เข้าใจผิดว่าข้อมูลเป็นปัจจุบัน; หากเครือข่ายขาดระหว่างเปิดหน้า จะแสดงข้อมูลล่าสุดในหน่วยความจำและแจ้งเตือน
- Google Apps Script มีโควตาและข้อจำกัดการเข้าถึงตามนโยบาย Google Workspace ของโรงเรียน ตรวจสอบสิทธิ์ Anyone และการเชื่อมต่อ cross-origin หลัง deploy จริง
